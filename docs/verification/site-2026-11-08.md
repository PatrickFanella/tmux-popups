# Instrument Panel product site review — November 8, 2026

**PASS — local conformance.** Landing page, docs and branded 404 implemented
on product baseline `d78bf16`. This report covers the website source in this
change, not a public deployment. The intended domain is
`https://tmux-popups.subcult.tv`.

## Scope and brand baseline

Pult's compact introduction → example → explanation → install → support
structure is the reference. The visual system comes from the owner-selected
tmux-popups Instrument Panel pack at Studio `f69b93c`. IBM Plex Condensed 700,
Sans 400/700 and Mono 400 are local Latin WOFF2 subsets; modified internal names
are Tmux Panel Condensed/Sans/Mono under the OFL. No terminal styling changes.
The [asset receipt](../site-brand.json) pins all nine selected assets, source
hashes, output hashes, tool versions and font transformations.

Matching behavior: unchanged pane/popup mark with clear space, 48px header and
32px footer sizes; square bordered panels; graphite, mint and amber roles;
proportional body text; mono commands; visible selection pointer and pressed
state. The menu and its synthetic project paths are labeled as an illustration.
The site omits a favicon because the pack has no approved 16px simplification.

horizontal overflow. All four font faces loaded; no broken images or unexpected
asset failures occurred on normal pages. Code and wide tables scroll inside
their own regions. Main navigation, docs anchors, install links and 404 return

All five illustration rows were clicked and produced their corresponding
description with exactly one selected row. Tab and Enter also changed selection.

Measured contrast: light text 13.88:1 on canvas / 11.81:1 on panel; muted text
8.35 / 7.11; mint 9.78 / 8.32; amber 11.02 / 9.38. Meaningful control boundaries
are 4.28 / 3.65. This checks used pairs; it is not a full WCAG certification or
screen-reader audit.

The ui-cliche scanner inspected five HTML/CSS/JS files and reported eight P1
heuristics. K7 misses the shared stylesheet's focus rules; I2 treats external
link arrows as emoji; SD5 flags the brand's mint headline line; SD2 flags the
owner-selected graphite/mint palette; K4 flags one recovery note's side rule.
These are deliberate or false positives in this context, not suppressed. There
was no prior web implementation for a before/after scanner comparison.
