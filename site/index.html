On at first load
Help, shell, daily notes, timer and tmux keys. Prefix + Enter opens the quick menu.
25 shipped entries
Optional adapters include lazygit, Yazi, logs, a calculator and more. Enable the ones you use and install their dependencies.
Your own tools
Add local scripts with literal JSON arguments. Choose popup, window or command mode. Reuse a tool window when you opt in.
Check before you launch
Help and the CLI show dependency status. Doctor checks the configuration. Existing prefix bindings are skipped by default.

Session switching stays with tools such as tmux-sessionx. Optional adapters need their own app configuration; a dependency check doesn’t validate accounts or credentials.

Get the toolkit

One line
in your config.

Add this to your tmux configuration with TPM, alongside your other plugins:

set -g @plugin 'PatrickFanella/tmux-popups'

Reload your tmux config, then press Prefix + I to install. Press Prefix + Enter to open the menu. Prefix means your configured tmux prefix, commonly Ctrl + b.

Installs from source. No tagged release is published yet. The launcher uses Bash and tmux; some optional helpers need Python 3 or other tools.
